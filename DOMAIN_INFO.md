### ¿Por qué el dominio dice "clipper"?

El dominio `clipper-manage-1` fue asignado al momento de crear el proyecto en Emergent Agent. Este es un identificador interno del sistema y permanece fijo durante toda la vida del proyecto.

**El nombre del dominio NO afecta**:
- ❌ El branding visible de la aplicación
- ❌ La funcionalidad del sistema
- ❌ La experiencia del usuario
- ❌ Los datos o configuración

### Para Producción

Cuando despliegues a producción, puedes:
1. **Configurar un dominio personalizado** (ej: `reservas.tubarber.com`)
2. **Usar un subdominio** (ej: `nexus.tubarber.com`)
3. **Configurar DNS** para apuntar a tu aplicación

### URLs de Reservas

Las URLs de reservas que compartes con clientes tienen el formato:
```
https://clipper-manage-1.preview.emergentagent.com/book/{organization_id}
```

Ejemplos:
- `https://clipper-manage-1.preview.emergentagent.com/book/org_demo001`
- `https://clipper-manage-1.preview.emergentagent.com/book/org_demo002`

**Nota**: En producción con dominio personalizado, serían:
- `https://tudominio.com/book/org_demo001`
- `https://tudominio.com/book/org_demo002`

### LocalStorage Keys

La aplicación usa las siguientes keys en localStorage:
- `nexus_theme` - Preferencia de tema (dark/light)
- `nexus_client_data` - Datos del cliente guardados

Todas las keys usan el prefijo "nexus" correctamente.
